# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Earlier than 1.0.0 | No |

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's "Report a vulnerability" option on this repository's Security tab, if it is enabled. If it is not available, open an issue asking for a private contact channel and leave out any technical detail.

Include the affected version, the impact, and the steps needed to reproduce the issue. Do not include real personal data or credentials in a report.

## Scope

This is a personal portfolio project with no service level or guaranteed response time. See [docs/SECURITY_AUDIT.md](docs/SECURITY_AUDIT.md) for the current review and known limitations.
